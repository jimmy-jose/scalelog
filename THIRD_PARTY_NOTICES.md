# Third-party notices and asset provenance

ScaleLog's original source code and documentation are licensed under [MIT](LICENSE). Third-party dependencies and media retain their respective licenses; the MIT license does not override those terms.

## Dependencies

The dependency versions are recorded in `package-lock.json`. Each installed package includes its own license information. Preserve any required copyright and license notices when redistributing dependencies or a bundled build. The root MIT declaration applies to ScaleLog, not to every package in `node_modules/`.

## Artwork

The character images, office background, app icon, and certificate preview are stored in `assets/characters/`, `assets/scenes/`, `assets/scalelog-app-icon.png`, and `docs/assets/certificate-preview.png`. [The asset brief](docs/asset-generation-brief.md) records generation directions for some artwork. Before public release, the maintainer should confirm ownership or redistribution permission for these assets and record any separate terms here. Until then, this document does not assign them an MIT license.

## Fonts

Certificate SVG artwork references Cormorant Garamond and Plus Jakarta Sans through Google Fonts. These font files are not checked into this repository. If bundling them for offline export or redistribution, include the applicable upstream font licenses and notices with the files.

## Adding or replacing assets

For each externally sourced asset, record its repository path, title, creator, original source URL, exact license, and required attribution. Include a copy of the license where required. A license permitting use in an application does not necessarily permit redistributing the raw asset in a public repository.
