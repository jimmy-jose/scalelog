# Support

For setup and gameplay, start with [the README](README.md). For campaign authoring, see [Adding campaign levels](docs/adding-levels.md). Certificate behavior is described in [the certificate guide](docs/certificates.md).

If the documentation does not answer your question, search [GitHub issues](https://github.com/jimmy-jose/scalelog/issues), then open an issue with your question, platform, and what you have tried. Use the bug report template for reproducible failures and the feature request template for proposals.

Remove credentials and personal player data from logs and screenshots. Security vulnerabilities should go through [private security reporting](SECURITY.md); community conduct concerns should go through [the code of conduct](CODE_OF_CONDUCT.md).

ScaleLog is maintained by volunteers. Help and contributions are welcome, but response times are not guaranteed.
